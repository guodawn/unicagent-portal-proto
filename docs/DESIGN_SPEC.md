# UnicAgent 企业门户前端统一设计规范 (DESIGN_SPEC.md)

> **版本**：v1.0.0  
> **适用范围**：UnicAgent 企业门户原型工程（`unicagent-portal-proto`）及后续生产研发实现

## 1. 设计系统基础与主题

### 1.1 组件库与主题包
- **核心组件库**：`@douyinfe/semi-ui` (^2.100.0)
- **图标系统**：`@douyinfe/semi-icons` (^2.100.0)
- **插画系统**：`@douyinfe/semi-illustrations` (^2.100.0)

## 3. 布局与间距规范 (Layout & Spacing)

### 3.1 版心与栅格
- **页面最大版心**：`1280px`（大屏自适应居中），内边距 `24px ~ 32px`。
- **导航高度**：固定吸顶 `68px`，`z-index: 1000`，带细边框与毛玻璃模糊。
- **板块垂直呼吸间距 (Section Spacing)**：
  - 核心板块上下 Padding：`96px ~ 120px`（硅基流动风格，留白充足、大气专业）。
  - 模块内标题与内容间距：`48px ~ 56px`。
  - 卡片网格间距 (Grid Gap)：`24px ~ 32px`。

### 3.2 容器与圆角 (Radius & Shadow)
- **小组件圆角 (Button/Tag/Input)**：`8px ~ 12px`；胶囊按钮 `9999px`。
- **标准卡片圆角 (Card)**：`16px`。
- **大容器/Banner圆角**：`20px ~ 24px`。
- **阴影规范**：
  - 常规卡片阴影：`box-shadow: 0 4px 20px rgba(15, 23, 42, 0.04)`
  - 悬浮卡片阴影 (Hover)：`box-shadow: 0 16px 36px rgba(110, 41, 246, 0.08), 0 4px 12px rgba(15, 23, 42, 0.05)`，伴随 `transform: translateY(-4px)` 平滑微动效。

## 4. 关键组件视觉规范

### 4.1 顶部导航栏 (PortalHeader)
- 左侧：UnicAgent 标志性科技 Logo，配合产品定位副标。
- 中间：核心菜单树（支持 Hover 触发 MegaMenu 展开大面板，展示结构化子菜单与说明）。
- 右侧：
  - 控制台入口（跳转运营管理后台）
  - 登录 / 注册入口
  - “免费体验 / 立即接入” 高亮渐变 CTA 按钮。

### 4.2 首屏 Hero 轮播 (HeroCarousel)
- 支持自动播放与平滑渐变切换。
- 采用深色/通透科技背景图，包含：
  - 状态胶囊标签（如 `🔥 硅基级高速推理引擎已上线`）
  - 大字号主标与主色高亮文案
  - 一句话核心价值说明
  - 双 CTA（主按钮“立即体验” + 次按钮“查看文档 / 预约演示”）。

### 4.3 核心指标与 LOGO 墙 (Trust & Metrics)
- 4 项大数字指标展示（如 99.99% 可用性、100+ 热门模型、10x 推理加速、200+ 标杆客户）。
- 知名央国企、汽车主机厂、能源电力集团、主流算力厂商的品牌 LOGO 墙。

### 4.4 核心产品矩阵 (Product Matrix)
- 采用 Tab 联动 + 左右图文 / 多卡片网格并排模式。
- 每个产品包含：
  - 业务标签与定位
  - 核心能力清单（带勾选图标）
  - 适用客群说明
  - 交互入口按钮（“了解更多 / 在线体验”）。

### 4.5 大模型广场预览 (Model Playground Showcase)
- 模型分类过滤（全部、通用大模型、推理大模型、代码大模型、多模态）。
- 模型列表卡片：展示模型名称、参数规模、上下文窗口（Context Length）、价格对比（¥ / 1M Tokens）、SLA 延迟指标。
- 交互功能：点击弹出「模型详情抽屉 (SideSheet)」，可直接在抽屉内发起单模型测试或多模型对比。

### 4.6 行业解决方案 (Industry Solutions)
- 垂直行业 Tab 切换：汽车、电力、能源、通用企业。
- 每个解决方案包含：业务背景与痛点、UnicAgent 赋能架构、典型客户案例与交付成果指标。

### 4.7 典型客户评价 (Testimonials)
- 真实客户背书卡片（客户肖像/Logo、岗位姓名、客户评价引言、应用场景）。

### 4.8 底部 CTA 转化区 (CtaBanner)
- 深紫渐变沉浸式全宽卡片，文案直接、按钮醒目，促使用户转化。

## 5. 原型专用工具栏规范 (PrototypeToolbar)
为方便产品经理进行需求评审与交互演练，继承参考项目 `unicagent-ops-proto` 规范：
- 屏幕右下角提供半透明轻量悬浮工具栏。
- 功能包含：
  1. **当前页面 PRD 需求备注**：悬浮提示当前页面的核心澄清目标与受众需求。
  2. **Mock 数据重置**：一键将本地缓存重置为出厂初始数据。
  3. **模型抽屉快捷触发**：方便快速测试模型详情与对比。
  4. **全屏演示模式**：隐藏原型工具栏用于高层汇报。
